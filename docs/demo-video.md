# BEAT Demo Video

This page provides the demo video for the AI for Good OPEA challenge submission.

## Demo Video

- [BEAT OPEA Demo Video](BEAT-OPEA-demo-video-short.mp4)

## Video Summary

The demo video shows the end-to-end workflow of BEAT: OPEA-based Enterprise SOP Coaching and Assessment Agent.

It covers:

- Online demo login
- Dashboard overview
- Training material and SOP management
- Knowledge preparation from enterprise files
- Intelligent practice workflow
- Answer assessment and feedback
- Learning records and dashboard analytics

## Key Message

BEAT is not only a chatbot. It is an OPEA-based enterprise GenAI application that turns SOP documents, operation manuals, training videos, and structured enterprise knowledge into a closed-loop workflow:

```text
Knowledge Preparation
    -> RAG-based Q&A
    -> Intelligent Practice
    -> Answer Assessment
    -> Evidence-backed Feedback
    -> Learning Analytics
```
