# mcp Microservice

This microservice is responsible for mcp.

## 🚀 Service Usage Guide

> **Note:** The examples below use `localhost` and specific ports applicable for Docker deployment. For Kubernetes deployment:
> 1. Get the service IP: `kubectl get svc -n <namespace>`
> 2. Replace `localhost` with the service IP in the commands below
> 3. Use the port exposed by the Kubernetes service

### 1. Start the Service

#### **Using Docker**
Run the following command to start the mcp service in a Docker container:
```bash
docker build -t mcp -f ./comps/mcp/Dockerfile .

docker run -d \
  --name mcp \
  -p 9999:9999 \
  -e MODEL_API_KEY=openai_api_key \
  -e MODEL_BASE_URL=your_llm_endpoint \
  -e MODEL_NAME=your_llm_model_name \
  -e AMAP_API_KEY=your_amap_api_key \
  -e WEBSEARCH_API_URL=your_websearch_api_url \
   mcp
```

### 2. mcp by links

You can send URLs to be mcp using a `POST` request:
```bash
curl -X POST \
    -H "Content-Type: application/json" \
    -d '{"text": "Where is WuHan","mcp_list": ["servers/search_tool.py"]}' \
    http://localhost:9999/v1/mcp
```

You can send the URLs to be mcp getting info about mcp tools using a `POST` request:
```bash
curl -X POST \
    http://localhost:9999/v1/mcp/infos
```

### 3. add mcp tool by python
#### Step 1: Modify your MCP tool code.[Official recommendation](https://modelcontextprotocol.io/quickstart/server)
```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("mcp_tool")

@mcp.tool("tool_function_name")
async def demo(param) -> str:
    """
      function description:
    Args:
        param info
    """
    return ""


if __name__ == "__main__":
    mcp.run(transport="stdio")
```

#### step 2: Add relevant configurations to `tool_config.json`,example as:
```json
[
  {
    "tool_name": "web_search",
    "tool_path": "servers/search_tool.py",
    "description": "Web search tool, which can use web search function to supplement real-time content",
    "type": "localhost", 
    "flag": "RAG" 
  }
]
```
flag：RAG or OTHER
type: localhost or url(Use 'localhost' for local Python or JS files; use a URL for network access, but network access is not yet implemented.)

### 5. How to use the two built-in tools, namely weather_tool and search_tool.
To use the search_tool, you need to first deploy the web_search microservice, because the search_tool essentially calls the API of this microservice.

To use the weather_tool, you need to first apply for an API key from Amap (Gaode), as this key is required for the tool to function.
